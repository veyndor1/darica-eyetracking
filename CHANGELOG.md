# Changelog

Based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [0.2.0] - 2025-05-31

### Added
- Scan keyboard (letter selection via blinks)
- Turkish word prediction
- Raspberry Pi support (picamera2 + pynput)
- Adaptive dead zone
- TPS gaze mapping
- Double blink clicking

### Fixed
- False positives in double blink detection
- Gaze accuracy
- Cursor jitter

## [0.1.0] - 2025

### Added
- Eye tracking based mouse control
- MediaPipe Face Landmarker integration
- 13-point calibration
- Kalman filter
- One Euro Filter
- EAR-based blink detection
- Ridge regression gaze model
